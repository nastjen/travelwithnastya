# Дананг — гайд / Da Nang guide

Гайд по Данангу, Хойану и Хюэ на русском и английском.

## Как опубликовать на GitHub Pages

1. Создайте новый публичный репозиторий на github.com (например, `danang-guide`).
2. Нажмите **Add file → Upload files** и перетащите туда `index.html`, `README.md` и папку `img` целиком.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/danang-guide/`.

Ссылка сразу на английскую версию: добавьте в конце `#en`.

Кнопки «Комментировать» работают только в Claude, на GitHub Pages они автоматически скрыты.
